# 策略信号源接口（交叉分析用）

本文件是 `concept_chain_analysis` 与 `racing_quant_pick` 做策略持仓 / 产业链吻合度交叉分析时的接口说明。策略库连接依赖由平台 `dependencies` 声明统一管理，完整字段定义见 `../racing_quant_pick/references/strategy-schema.md`。

## 交叉分析需要的字段

| 字段 | 含义 | 用途 |
|---|---|---|
| `strategy_id` | 策略唯一标识 | 关联策略名称与说明 |
| `strategy_desc` | 策略中文简介 / 关键词 | 与产业链环节、偏好做语义匹配 |
| `holdings[]` | 持仓明细 | 判断受益环节是否已被策略覆盖 |
| `holding.code` | 证券代码 | 映射产业链标的 |
| `holding.name` | 证券名称 | 报告展示 |
| `holding.weight` | 仓位权重 | 判断覆盖强度与遗漏环节 |
| `as_of` | 持仓日期 | 标注数据截止日，避免用陈旧数据下结论 |

## 使用约定

- 本技能**不重复直连**策略库，统一经 `racing_quant_pick` 取数后再做产业链映射。
- 策略库视为「策略信号源」，与行情数据源分层，不进入行情网关降级链。
- 字段缺失或取数失败时，如实标注「策略信号源不可用」，不得编造持仓或映射关系。
- 交叉分析只输出吻合度、遗漏环节与潜在补配方向，不替代个股深度诊断。
